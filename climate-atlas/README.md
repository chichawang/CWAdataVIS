# 臺灣氣候 GIS（大氣變數視覺化）

入口為 [index.html](index.html)（Leaflet 時空 GIS 地圖）；統計圖表與資料表格探索介面保留於 [table-explorer.html](table-explorer.html)。

## 本階段範圍：聚焦 12 項大氣變數資料集

本版依開發優先順序先完成 **大氣變數視覺化**，分為四大主題共 12 筆官方開放資料集：

1. **地面測站氣象 (`station`)**
   - `C-B0024-001`：30 天觀測資料（逐日大氣統計與逐時觀測）
   - `C-B0024-002`：一年觀測資料（逐日／逐月大氣統計與近 30 日逐時觀測，支援大檔串流下載進度）
   - `C-B0026-001`：每月氣象-地面測站資料
   - `C-B0026-002`：每月氣象-過去 9 年地面測站每月氣象資料（自動解壓 ZIP 內逐月 XML）
   - `C-B0027-001`：月平均-地面測站資料（30 年氣候月平均 1–12 月）
2. **地面測站降雨 (`rain`)**
   - `C-B0025-001`：每日雨量-地面測站每日雨量資料（逐月總雨量與逐日降水量）
   - `C-B0025-002`：每日雨量-過去 9 年地面測站每日雨量資料（自動解壓 ZIP 內逐年 XML，彙整歷年逐月、年總雨量與近兩年逐日雨量）
   - `C-B0025-003`：每日雨量-過去一季每日雨量資料（620+ 有人與自動雨量站）
3. **農業氣象觀測 (`agri`)**
   - `C-A0008-001`：農業氣象觀測網旬資料（59 站氣溫、濕度、雨量、風速、日照、日射與 0–100 cm 地溫）
   - `C-A0009-001`：農業氣象觀測網月資料
4. **月氣候面化圖集 (`maps`)**
   - `C-B0072-001`：月雨量面化圖（自動解壓 ZIP 內 1–12 月 KMZ 之 KML `LatLonBox` 與 PNG 疊圖）
   - `C-B0072-002`：月氣溫面化圖（自動解壓 ZIP 內 1–12 月 KMZ 之 KML `LatLonBox` 與 PNG 疊圖）

### 暫緩項目（先不做獨立視覺化）

- **海象／波浪／暴潮／海溫／潮位（9 筆）**：`C-A0088-001`、`C-A0090-001`、`C-A0092-001`、`C-A0094-001`、`C-B0049-001`、`C-B0050-001`、`C-B0051-001`、`C-B0052-001`、`C-B0086-001`
- **測站基本資料（2 筆）**：`C-B0074-001`（有人站）、`C-B0074-002`（無人站）。不另建獨立視覺化圖層，已萃取出 48 座地面氣候測站 WGS84 經緯度、縣市與海拔內建於 `catalog.js`（`STATION_COORDS`），供未附座標的 `C-B0024/25/26/27` 自動定位。

## 使用方式

建議在專案根目錄啟動本機伺服器後開啟 `climate-atlas/index.html`：

```bash
python -m http.server 8765 --bind 127.0.0.1
```

瀏覽 `http://127.0.0.1:8765/climate-atlas/`：

1. 選擇四大主題之一與大氣資料產品。
2. 點擊「載入官方資料」即可直接透過氣象署公開開放端點（或選填個人 CWA 授權碼）自動解析並上圖；亦可匯入本機 JSON / XML / ZIP / KMZ / CSV / GeoJSON（上限 250 MB）。
3. 地圖右上角「切換大氣變數」下拉選單可即時切換著色要素（氣溫、最高／最低溫、雨量、降水日數、濕度、氣壓、風速、日照、日射、地溫等）。
4. 圖例面板顯示鎖定全期的專屬色階與當期全臺最高站／最低站／平均統計；點選任一測站可查看各要素卡片與時間變化曲線。
