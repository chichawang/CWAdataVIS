全球官方颱風路徑整合圖 arrow_forward
彙整 CWA、JMA、JTWC、NHC、CMA、HKO、KMA 等官方氣象機構熱帶氣旋預報路徑，可總覽全部系統或切換單一颱風比較各機構預報。 key 內建 CWA 示範授權碼，可自備 API 授權碼
NWP/MLWP 系集颱風路徑預報 arrow_forward
整合 TIGGE 傳統數值模式與 Google WeatherNext2 機器學習天氣模式（MLWP）熱帶氣旋系集路徑，支援多模式成員線、集合平均、指定時效落點播放、侵襲機率場、強度時序與全球/洋盆篩選；開啟後會依預設起報時間自動載入。 lock_open 不需 API 金鑰，部分遠端資料可能受跨網域限制
台灣即時影像地圖 arrow_forward
全臺 5,586 支公開即時影像鏡頭整合於單一地圖：公路局省道交控、國道路況、新北與嘉義縣市 CCTV、水利署河川監控、水利防災、水土保持、土石流監測、臺南與嘉義水情。 支援即時快照／MJPEG／HLS 串流／iframe 四種影像型態，可依分區與 11 種分類勾選、鏡頭名稱與路線搜尋、收藏常用鏡頭（存於瀏覽器）、切換底圖與定位目前位置。 省道鏡頭可即時改抓公路局最新 CCTV 清單。 lock_open 不需任何 API 金鑰，開啟即用
水利署即時水位地圖 arrow_forward
經濟部水利署開放資料整合圖，七個可疊加圖層：河川即時水位（857 站，依一／二／三級警戒水位分級上色，達警戒站加脈動標示）、即時地下水位觀測井（井位取自水利署地理資訊服務平台 KMZ，可看水位高程／埋深／井況）、以及智慧防汛物聯網（IoW）的淹水深度、揚塵 PM10、閘門相關監測、沖刷深度、累計流量（雨水貯留）五種感測器。 支援縣市→水系→河川三層連動篩選、站名／站號／地址搜尋、只顯示達警戒測站、隱藏逾時未更新的感測器，並以網址 hash 保存目前的圖層與篩選狀態，可直接分享連結。 lock_open 不需任何 API 金鑰，開啟即用
環境部空氣品質監測地圖 arrow_forward
環境部環境資料開放平臺空品監測整合圖：以 AQI 六級標準色呈現全臺測站，可切換 19 種測項（PM2.5／PM10／O₃／SO₂／NO₂／CO 依 AQI 分級上色，另有 NO／NOx／CH₄／NMHC／THC 與溫濕度、雨量、氣壓、風向風速箭號）。 側欄含各空品區未來數日 AQI 預報、全臺極值統計、縣市與測站類型篩選；可疊加河川揚塵監測、特殊性工業區監測與光化測站 50＋ 種 VOC 物種圖層。 點選測站可載入該站單站資料集畫出近日逐時變化圖。 key 需 MOENV API KEY（頁面已內建預設金鑰，可直接進入）
